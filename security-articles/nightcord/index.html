NightCord – Fake Discord Client with Token Logger

A Vencord fork that promises to enhance your Discord experience – while stealing your account.

Warning

NightCord is NOT a safe Discord client. Installing it puts your Discord account at risk of being stolen. The original GitHub repository was taken down after substantial evidence of token theft was uncovered. The developers deny everything, but old versions of the code prove the malicious intent beyond doubt.

What Is NightCord?

NightCord posed as an enhanced Discord client — similar to Vencord or BetterDiscord. It was advertised as a visually upgraded alternative with extra features. In reality, it was disguised malware designed to steal Discord tokens.

The GitHub repository — and most likely the associated website — have been taken down. However, old versions are still circulating through Discord servers, forums, and direct messages.

How the Token Theft Works

NightCord contained hidden code that executed automatically when the client started, reading the Discord token from local storage and sending it to a remote server controlled by the attackers. In older versions that are still being spread, this code is clearly identifiable as a token logger.

What Can Attackers Do With Your Token?

A Discord token is the complete key to your account. With a token, attackers can:

  • Gain full account access — They can impersonate you without needing your password or 2FA. Discord does not prompt for re-authentication.
  • Read private messages — All DMs, group chats, and server messages are visible.
  • Send messages as you — They can send spam, scams, or malicious links to your friends and contacts, spreading the attack further.
  • Join or leave servers — Your account can be invited to servers or leave existing ones.
  • Perform administrative actions — If you have admin permissions on a server, attackers can ban members, delete messages, rename channels, and sabotage the server.
  • View payment methods — If you have Discord Nitro or made purchases, stored payment information (PayPal, credit card) can be accessed.
  • Maintain persistent access — Even if you change your password, the stolen token remains valid until you log out all sessions under Discord settings → "Log Out All Known Devices".

How to Protect Yourself

  • Never install modified Discord clients from untrustworthy sources. Only use the official Discord app or well-known open-source clients like Vencord that are audited by the community.
  • Always check the source code before installing anything. If a client claims to be "closed source," that is a massive red flag for security software.
  • Use Discord in your browser for unknown or risky clients — the browser isolates sessions better than the desktop app.
  • Regularly update your password and use the "Log Out All Known Devices" option in Discord's security settings.
  • Enable 2FA While 2FA does not protect against token theft, it makes it harder for attackers to access your account through other means.

Have I Been Compromised?

If you have ever installed NightCord, assume your token has been compromised. Follow these steps immediately:

  1. Open Discord → User Settings → "My Account"
  2. Click "Change Password" — this invalidates your current token
  3. Go to "Devices" and click "Log Out All Known Devices"
  4. Also change your email password if it was the same
  5. Review your authorized apps under "Authorized Apps" and remove anything unknown

Conclusion

NightCord is yet another example of disguised malware spreading through the Discord community. The developers deny the allegations, even though old versions clearly prove the token theft. The repository was rightfully removed. But old versions are still in circulation — do not install NightCord under any circumstances.

Stay vigilant and question any "enhanced" client offered to you in Discord servers or DMs. If something looks too good to be true, it most likely is.
