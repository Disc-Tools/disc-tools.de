Look things up

  • User Lookup Badges, account age and details for any user ID. Discord login required.
  • Username History Premium Every past username and discriminator of an account.
  • Server Lookup Members, channels and invites via Discord’s widget API. Discord login required.

Accounts & Premium

Check which tools you can use right away and when you’ll need to sign in.

Which tools work without signing in?

You can use Timestamp Generator, Markdown Generator, Snowflake Decoder and more without an account.

How does Discord login work?

Tools such as User Lookup and Invite Lookup use Discord OAuth2. You sign in on Discord and can review the requested permissions before granting access. See the Privacy Policy for details about account data.

What comes with Premium?

Premium unlocks tools such as Username History and Alt Account Lookup. See Premium plans and features.
