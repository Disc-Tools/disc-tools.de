Creating Discord Embeds

Learn how to use the visual Embed Builder to create, preview, and send rich embeds to Discord.

What is a Discord Embed?

Embeds are rich content blocks that can be attached to Discord messages. They support formatted text, images, fields, colors, and more. Our Embed Builder lets you create them visually without writing any code.

1

Fill in the Fields

Use the left-side editor to add embed content: author, title, description, color, fields, image, thumbnail, and footer. Every change updates the live preview instantly.

2

Add Fields

Click "Add Field" to create embed fields. Each field has a name, value, and optional inline display. Inline fields sit side by side, perfect for stats or comparisons. You can reorder fields by using the arrow buttons.

3

Choose a Color

The color picker sets the colored bar on the left side of the embed. Enter a hex code directly or use the native color picker to find the perfect color for your brand or server.

4

Export or Send

Once you are happy with your embed, you have several options:

  • Copy JSON — Copy the raw JSON to use in bots or API calls
  • Export JSON — Download the embed as a .json file
  • Import JSON — Load a previously saved embed from a file
  • Send to Webhook — Paste a webhook URL and send the embed directly
5

Webhook Payload Format

Switch to "Webhook Payload" tab in the JSON output to see the full payload format. This includes the username and avatar_url fields, making it ready to POST directly to any Discord webhook endpoint.

Tips & Best Practices

  • Use inline fields sparingly — too many inline fields can look cramped on mobile
  • Footer timestamps are automatically set to the current time when enabled
  • You can use Markdown in the description and field values (**bold**, *italic*, ~~strikethrough~~)
  • Image URLs must point directly to a media file (ending in .png, .jpg, .gif, etc.)
  • Discord recommends keeping total embeds under 6000 characters
