How to use Server Lookup

Fetch public data via the Discord Widget API.

What is Server Lookup?

This tool uses Discord's official Widget API to fetch public information about a server. Note that this only works if the server has "Enable Widget" turned on in their settings.

How to use it?

1

Get a Server ID

Right-click a server icon in Discord and select "Copy Server ID". (Developer Mode must be enabled).

2

Lookup

Paste the ID into the input field and click "Lookup".

3

View Public Data

You'll see the server name, member count, and a list of online members and channels that are public via the widget.
