How to use Invite Lookup

Inspect Discord invites before you join them.

What is Invite Lookup?

This tool allows you to peek into a Discord invite link. You can see which server it leads to, how many members it has, who created the invite, and when it expires—all without actually joining the server.

How to use it?

1

Get an Invite Link

Copy any Discord invite link (e.g., discord.gg/codes or https://discord.com/invite/codes).

2

Lookup

Paste the link or just the code into the tool and click "Lookup".

3

Analyze Server Data

View the server's Name, Icon, Member Counts, and security level. It also shows you the inviter's details if available.
