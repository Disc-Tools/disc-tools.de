Emoji Picker

Open the emoji, GIF, and sticker pickers with keyboard shortcuts.

Syntax

How it works

Press the shortcut to open each picker

Ctrl+Shift+I for emojis

Examples

Shortcuts

  • Ctrl+Shift+I — Emoji Picker
  • Ctrl+Shift+G — GIF Picker
  • Ctrl+Shift+S — Sticker Picker

On Mac, use Cmd instead of Ctrl.

Quick Typing

Type : followed by a name to search emojis inline. For example, :rocket: produces 🚀.
