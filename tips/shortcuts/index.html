Search messages, files, and links in the current channel or server.

Navigation

Navigate between messages, channels, and servers with the keyboard.

Alt+↑ Alt+↓ Ctrl+Alt+↑

Quickly mark the current channel or server as read.

Esc / Shift+Esc

Previous / Next Channel

Alt+↑ prev   Alt+↓ next
