Navigation

Navigate Discord entirely with your keyboard — no mouse needed.

Syntax

How it works

Arrow through messages, servers, and channels

Alt+↑ Alt+↓ etc.

Examples

Message Navigation

  • Alt+↑ / Alt+↓ — Jump to previous/next message
  • Ctrl+Alt+↑ / Ctrl+Alt+↓ — Jump to previous/next channel

Server __EXTRA_CONTENT__ Channel List

  • Ctrl+Shift+↑ / Ctrl+Shift+↓ — Navigate servers
  • Alt+↑ / Alt+↓ — Navigate channels within a server
  • Ctrl+Shift+Backspace — Focus last unread channel

On Mac, use Option instead of Alt and Cmd instead of Ctrl.
