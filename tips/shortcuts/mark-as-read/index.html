Mark as Read

Clear the unread indicator on a channel or server instantly.

Syntax

How it works

Press Esc for channel, Shift+Esc for server

Esc or Shift+Esc

Examples

Channel

Press Esc to mark the current channel as read.

Server

Press Shift+Esc to mark every channel in the current server as read.
