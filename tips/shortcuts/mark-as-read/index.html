Mark as Read

Quickly mark the current channel or server as read.

Desktop
Press this
Esc Mark current channel as read
Shift+Esc Mark current server as read
What it does

Clears the unread indicator for the channel or server you are viewing, letting you catch up without scrolling every message.

Use Shift+Esc to mark an entire server read at once. Combine with navigation shortcuts to triage unread channels quickly.
