Upload File

Open the file picker to attach images, videos, documents, and more.

Syntax

How it works

Press the shortcut to open the file browser

Ctrl+Shift+U or Cmd+Shift+U

Examples

How to Upload

Press Ctrl+Shift+U (Windows) or Cmd+Shift+U (Mac) to open your file browser. Select files to attach them to your message.

You can also simply drag __EXTRA_CONTENT__ drop files into the Discord window.

Limits

  • File size limit: 10MB (25MB with Nitro Basic, 500MB with Nitro)
  • Supported formats: images, video, audio, documents, archives
