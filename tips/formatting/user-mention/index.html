User Mention

Ping a specific user by their Discord ID.

Syntax

Normal Mention

Place a user ID between <@ and >:

<@123456789012345678>

Discord renders this as a clickable ping.

Nickname Mention

Use <@! to mention by nickname instead of global name:

<@!123456789012345678>

The ! variant tells Discord to show the server nickname if available.

How to get a User ID

1

Enable Developer Mode

Go to User Settings > Advanced and toggle Developer Mode on.

2

Copy User ID

Right-click (or long-press on mobile) a user's name or avatar and select Copy User ID.

Tip

Type @ in the chat box to autocomplete a username — no ID needed!
