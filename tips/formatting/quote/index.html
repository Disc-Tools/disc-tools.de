Quote

Reply-style block quotes using __HERO_DESC__gt; for single lines and __HERO_DESC__gt;__HERO_DESC__gt;__HERO_DESC__gt; for multi-line.

Syntax

How it works

Prefix a line with > for a single quote, >>> for multi-line

> text

Examples

1

Single Line Quote

> This is a quote
2

Multi-Line Quote

>>> This is a multi-line quote.
