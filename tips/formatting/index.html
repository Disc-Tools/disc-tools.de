Message formatting

Add emphasis, structure, links and timestamps to your Discord messages. Copy the syntax or open a guide for examples.

18 of 18 examples

Text styles 7

Bold

Make text stand out. Wraps the word in double asterisks.

**text**→text

Italic

Subtle emphasis for quotes, titles or asides.

*text*→text

Bold + Italic

Maximum emphasis — combine both styles in one marker.

***text***

Underline

Discord-only style. Great for headings inside a message.

__text__→text

Strikethrough

Cross text out — perfect for edits without deleting.

~~text~~→text

Spoiler

Blur content until someone clicks to reveal it.

||text||

Subtext

Small grey footnote text. Must start on its own line.

-#subtext
Structure & blocks 6

Headers

Three headline sizes for rules, announcements and events.

#Big##Medium###Small

Lists

Bulleted or numbered lists — indent with 2 spaces.

-item1.item

Quote

Single-line quotes with >, whole-message quotes with >>>.

>text/>>>multiline

Inline Code

Highlight commands, variables or single words.

`code`

Code Block

Multi-line blocks with optional language highlighting.

```jscode```

Masked Links

Clickable label instead of a raw URL. Best in embeds & bots.

[label](url)→label
Mentions, time & extras 5

Timestamp

Auto-converts to every reader's timezone. Try :R for countdowns.

<t:unix:R>→in 2 hours

Channel Mention

Clickable channel link — needs the channel ID.

<#id>→#channel

User Mention

Ping a specific user by ID, even without autocomplete.

<@id>→@user

Role Mention

Ping a whole role. Use sparingly — it notifies everyone.

<@&id>→@role

Custom Emoji

Post server emoji by name + ID. Prefix with a if animated.

<:name:id>

Combine styles

Most markers stack. The most useful combos:

  • ***bold italic*** → bold italic
  • __*underline italic*__ → underline italic
  • ~~__underline strike__~~ → underline strike
  • ||`spoiler code`|| → hidden code

Where do I get IDs?

Channel, user, role and emoji syntax all need numeric IDs:

  • Discord Settings → Advanced → enable Developer Mode
  • Right-click a user / channel / role → Copy ID
  • Emoji: type \:name: in chat to reveal <:name:id>

Good to know

  • # ## ### and -# only work at the start of a line.
  • [label](url) renders reliably in embeds, bots & webhooks — typed manually it may stay raw (anti-phishing).
  • Use <https://…> to post a link without the big preview card.
  • Escape a marker with backslash: \*not italic\*.
