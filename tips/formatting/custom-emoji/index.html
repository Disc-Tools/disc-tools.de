Custom Emoji

Use custom emoji from any server your bot shares.

Syntax

Static Emoji

Use <:name:id> to reference a static custom emoji:

<:pepega:123456789012345678>

Animated Emoji

Use <a:name:id> for animated emoji (Nitro required):

<a:popcat:123456789012345678>

The a stands for animated.

How to get an Emoji ID

1

Enable Developer Mode

Go to User Settings > Advanced and toggle Developer Mode on.

2

Copy Emoji ID

Send the emoji in chat, then right-click it and select Copy Emoji ID. Alternatively, use our Emoji Stealer tool to get the ID and download link.

Tip

Type : in the chat box followed by the emoji name to autocomplete — no ID needed if you share a server with that emoji!
