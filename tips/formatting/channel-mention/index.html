Channel Mention

Link a channel by its ID so others can click and jump there.

Syntax

Basic Usage

Place a channel ID between <# and >:

<#123456789012345678>

Discord automatically converts it to a clickable channel link.

How to get a Channel ID

1

Enable Developer Mode

Go to User Settings > Advanced and toggle Developer Mode on.

2

Copy Channel ID

Right-click (or long-press on mobile) any channel in the sidebar and select Copy Channel ID.

3

Use it

Paste the ID into your message: Hey, check out <#123456789012345678>lt;#123456789012345678<#123456789012345678>gt;!

Tip

You can also just type # in the chat box to autocomplete a channel — no ID needed!
